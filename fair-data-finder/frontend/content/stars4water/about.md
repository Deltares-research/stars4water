# About the STARS4Water Metadata Portal

## What is the STARS4Water Metadata Portal?

The STARS4Water Metadata Portal is a central discovery platform designed to help water managers, river basin authorities, researchers, and policymakers find datasets relevant to water resources management and climate adaptation. Rather than creating another data repository, the portal aggregates metadata from many existing sources and provides links back to the original data providers. The portal was developed as part of STARS4Water WP2 ("Unlocking and improving data services") to unlock underused datasets from initiatives such as Copernicus, GEOSS, JRC activities, previous EU projects, and regional river basin data sources.

The core philosophy underlying the portal is: **Metadata, not data**. A key design principle is that the portal does not store most datasets itself. Instead, it functions as a metadata catalogue and discovery service. Metadata records describe datasets and provide links to the authoritative source. The Portal functions solely as a metadata catalogue and discovery service.

This approach was chosen because it:

- Improves findability by bringing metadata from many repositories into one searchable environment.
- Preserves data integrity because users access the original provider's most up-to-date version.
- Avoids duplication of storage and maintenance effort.
- Supports FAIR data principles, particularly Findability and Accessibility.

The portal contains metadata describing datasets about, amongst others, hydrology, climate, water quality, water use, and environment. Users can search datasets geographically and thematically.

The portal also contains the metadata of open data produced by STARS4Water. Project-generated datasets have been published in repositories such as Zenodo with Digital Object Identifiers (DOIs) and FAIR-compliant metadata, after which their metadata are uploaded to the portal to increase discoverability. FAIR data stands for Findable, Accessible, Interoperable and Reusable.

While the metadata are FAIR compliant, data findability (F) is the first element of FAIR data management. Most data in the metadata portal are also accessible (A). Whether they can easily be reused (R) — both from an interoperability (I) and data quality point of view — depends on a match between the user's needs and the data provider's detailed metadata.

## User guide

### Search functionality

The Stars4Water Metadata portal is designed for intuitive exploration of water-related metadata. Here's how you can get started:

- Search the catalogue by searching for words in titles and descriptions. Only single word search is currently supported.
- Use the "Clear Filters" button to reset the search.
- Search the catalogue by applying the filters on the left-hand side, using the dropdown menus:
  - Domain: to only select datasets collected during STARS4Water.
  - Topic: navigate through predefined topics/categories such as Hydrology, Climate, and Water Quality for structured browsing.
  - Keyword.
  - Collection period of the data.
- Search the database by using the map and drawing a polygon on the map to search for datasets in a specific area. The geographic coverage of a dataset is one of the associated metadata fields, represented as a polygon. When you select a polygon on the map, all datasets which may have data within that polygon will appear.
- Please note that most datasets have global coverage, which explains the large number of datasets positioned in Africa.
- Please note that not all datasets contain geographic coverage information. Such datasets hence cannot be found using this search method.

### Understanding Search Result Icons

When you search in the portal, results are displayed with different icons to help you quickly identify their type:

- **Blue Circles**: When multiple datasets share the same location, a blue circle with a number is shown. The number indicates how many datasets are linked to that point. This can include datasets at the exact same point or datasets whose polygons cover that location.
- **Location Pins**: For a single dataset, a location pin is displayed. If the dataset represents an area (polygon), the pin is placed at the centre of that polygon.

### View Metadata & Access Original Data

- Click on any dataset to view detailed metadata, including description, source, and usage rights.
- Follow the provided links to access the original data at its source.

A tutorial explaining the metadata portal can be found in The STARS4Water Academy.

## Adding data & contact

If you have questions or comments about the metadata portal, please use the Contact form on the project website.

Data-owners interested in having their metadata included in the metadata portal can contact the hosting organisation through the [contact form of the Stars4Water project](https://stars4water.eu/contact/), providing some preliminary detail of the nature and number of data sets.

The portal's team will review requests on a regular basis and, upon acceptance, provide the metadata template.
